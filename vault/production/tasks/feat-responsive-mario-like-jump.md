# feat: Responsive Mario-like jump

Цель: отзывчивый прыжок для преодоления низких препятствий и перепадов уровней; игровой контроль важнее физической точности.

Acceptance MVP:

- jump buffer и coyote time;
- переменная высота по удержанию/отпусканию;
- быстрый контролируемый спад;
- возможность перепрыгивать только явно помеченные низкие blockers;
- корректное приземление на активный floor.
