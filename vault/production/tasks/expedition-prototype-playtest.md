# Прототип: провести плейтест и пересчитать объём

Intent: Проверить, понятны ли цель, повторяемые свойства и смысл выбора, до роста контента.

Specification: [[GDD]] — A1–A8; [[production/roadmap/rat-expedition-release-roadmap|План до релиза]] E2.

Dependencies: [[expedition-prototype-integrated-scenario]]. До закрытия зависимостей не брать в работу.

## Acceptance

- Три новых игрока пробуют зафиксированную сборку без объяснения решения; приглашения/контакт с участниками делает человек, агент не рассылает сообщения автоматически.
- Для каждого записаны найденный путь, понимание цели, предсказание второго применения, путаница в диалоге/бою и собственные слова об интересе; минимум двое достигают порога A8.
- Отдельно пройдены все маршруты/концы боя и нет необратимых тупиков/потери прогресса. При недоступности участников результат остаётся неполным, не заменяется агентской симуляцией игрока.
- Измерены часы реализации, исправлений и одного элемента контента; потолок A2/будущая оценка пересчитаны с резервом, без обязательного увеличения длительности.
- В журнале решений записаны сохранить/изменить/сократить по каждой затронутой гипотезе; блокеры получают карточки и повторный целевой плейтест.
- Только после положительного решения детализируется E3; отрицательный результат останавливает следующий этап.
