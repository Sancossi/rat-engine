# Прототип: сохранение последствий и ресурсов

Intent: После загрузки игрок продолжает тот же квест, без потерянного обещания или повторной награды.

Specification: [[GDD]] — Сохранение и интерфейс; архитектура выбранного движка из [[expedition-engine-decision]].

Dependencies: [[expedition-prototype-combat]]. До закрытия зависимостей не брать в работу.

## Acceptance

- Три ручных слота и отдельный автослот работают в устойчивом исследовании; сохранение в бою/разговоре/подъёме/перемещении груза/переходе отказывает с объяснением.
- Roundtrip сохраняет область/позицию, партию/ресурсы/ранг, инвентарь, способ квеста, обещание, пути, грузы, горючие преграды, врагов и одноразовые награды.
- Автосохранение после перехода/квестового шага содержит целый результат; поражение не затирает слот; снимок перед боем не подменяет ручной.
- Ошибка/несовместимая версия чтения не меняет текущую игру; ошибка записи сохраняет предыдущий рабочий слот. Есть отрицательные проверки с повреждённым файлом и имитированной ошибкой записи.
- Ручной тест перезапуска процесса до/после сдачи жетона и победы подтверждён; повторные загрузки не дают повторный предмет/ранг.

## Границы

Новая игровая схема по принятой архитектуре; без миграции старых rat-engine save и сохранения посреди VM/боя.
