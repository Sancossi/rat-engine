# Прежняя концепция и очередь: что сохраняем

Срез 2026-09-08. [[ADR-016 Rat expedition concept reset]] заменяет игровые ограничения, не переписывает выполненную инженерную работу. Этот документ оценивает применимость; он не меняет статусы и не разрешает автоматически брать старые карточки.

## Завершённые основы

Перемещение, лестницы/высоты, граф событий, состояния/инвентарь, строгие сохранения, тестовый harness и editor authoring — существующий инженерный опыт. В rat-engine пригодность конкретного API проверяется новым сценарием; в другом движке переносятся требования, контент и сценарии тестов, а не автоматически C++ реализация. Старые карты/сохранения не объявляются форматом новой игры.

Реестр ассетов и MemoryAssetLoader — scaffolding, не готовый импорт спрайтов. Пошаговый бой и представление 2D-персонажей предстоит сделать. Текст старого architecture roadmap о будущих слоях не означает существующие CMake targets; Sprint 15 закрыт, старая строка об активной очереди не действует.

Новая карточка взаимодействий ссылается на исходную идею; обратная связь хранится здесь и в родительской карточке подготовки. Старые карточки намеренно не редактируются при сохранении пользовательских изменений; ведущий агент может добавить точные Follow-up при следующей работе с ними. Закрытые задачи и предыдущие спринты остаются закрытыми.

## Навигация и сохранение истории

[[legacy-gdd-2026-08-31]] — точная копия предыдущего GDD, включая его прежние рабочие решения. Актуальная точка входа — [[rat-expedition]]. Чистый HOME обновлён, чистая [[Art Direction]] получила только исторический баннер. Старые Narrative, Audio Direction, Rat Project, Roadmap и ADR с пользовательскими изменениями сохранены байт-в-байт; хаб новой экспедиции ведёт к актуальным источникам.

Состояние реальных файлов проверяется по сохранённому ведущим агентом baseline, а не по предположению, что git status должен стать пустым. Новые задачи вне текущего спринта остаются Not started. Список их зависимостей — [[production/roadmap/rat-expedition-release-roadmap|План до релиза]].
