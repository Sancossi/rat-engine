# How we work

The shared [AGENTS.md](../../AGENTS.md) defines capture, delegation, status, review,
commit and sprint rules for all coding agents. The git vault is the product hub.

Plan a sprint from [[Roadmap]] and backlog; record its goal and ordered cards.
Zero active sprints is valid between stages; execution has exactly one current sprint.
Review shipped work, carry forward linked followups, and record a short retrospective.

A completed task is `Done`; a repaired bug is `Fixed`. Both require approved review,
Resolution with validation evidence, and Bugs found (or `none`). Update [[Systems Index]]
and [[GDD]] when their contracts change. Use [[Task board]] for tasks and bugs.

New durable requests and discovered in-scope defects get deduplicated cards and
bidirectional Origin / Follow-up links. Unrelated ideas stay in backlog.
