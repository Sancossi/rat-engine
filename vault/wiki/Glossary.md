# Glossary

## Engine

- **Frame** — один цикл update/render.
- **Scene** — контейнер игрового состояния.
- **Asset** — загружаемый ресурс с handle/id.

## Game

- **Pillar** — неизменяемый дизайн-принцип.
- **Core loop** — повторяемый цикл мотивации → действия → награды.
- **Vertical slice** — вертикальный срез контента end-to-end.

## Production

- **Sprint** — фиксированное окно работы с Goal.
- **ADR** — Architecture Decision Record в [[Decisions]].
- **Vault** — Obsidian-волт в `vault/`, источник правды для хаба.
