# Канальный город — исходный набор Дрёммы, 2026-09-09

## Результат и границы

Подготовлен исходный срез первого этапа по [спецификации каталога](../canal-city-catalog-spec.md)
и [последнему масштабу Дрёммы](../dremma-scale-spec.md): 12 моделей, 2 дверных клипа,
45 процедурных PNG-карт, редактируемый Blender-файл и 4 сравнительных рендера.
Реестр содержит 135 записей: 12 имеют `validated_blender_fbx`, остальные 123 —
`pending`, без вымышленных source/export путей. Native-статус остаётся
`pending_A1_qualification` у всех записей.

Работа выполнена в `feat/canal-city-catalog`, исходный HEAD `a3b6bad`.
Checkpoint `d8b513e` сохранён в истории и описывает прежний масштаб. Текущий
набор заменяет его технические артефакты, сохраняя предыдущие размерные трактовки
в `previous_dimension_revision`. Первое независимое ревью выявило три P2;
исправления и повторная проверка исполнителя описаны ниже. Независимое повторное
ревью ожидается; этот отчёт не закрывает карточку и не разрешает публикацию этапа
как принятого.

Исходники и машиночитаемое evidence находятся в
[Resources/CanalCity](../../games/rat-expedition/Rat.Expedition.Authoring/Resources/CanalCity/):
`canal_city_foundation.blend`, `catalog.json`, `generation-report.json`,
`validation-report.json`, `models/`, `animations/`, `textures/`, `fonts/`, `previews/`.

## Проверка доставленных файлов

Среда: Windows, Python 3.14.4; Blender **5.2.0 LTS**, hash `fbe6228777e7`,
build `2026-07-14 01:35:40`. Проверка запускается из корня рабочей копии:

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' --factory-startup --background --python-exit-code 1 --python games/rat-expedition/tools/canal_city/validate.py -- --input games/rat-expedition/Rat.Expedition.Authoring/Resources/CanalCity --report build/canal-city/source-reviewfix-validation.json
python scripts/check_vault.py
python -m unittest discover -s scripts/tests
git diff --check
```

Все команды завершились с кодом 0; vault checker прошёл, **25 Python-тестов**
прошли. Свежий `source-reviewfix-validation.json` структурно совпадает с доставленным
`validation-report.json`. SHA256 всех **66** перечисленных файлов совпали.
Состав хешируемых файлов: Blender, 14 FBX, 45 PNG-карт, 4 PNG-превью, шрифт и OFL.
JSON-манифесты не входят в эту хеш-таблицу; их история фиксируется Git.
Локальный `fonts/.gitattributes` сохраняет оригинальные байты OFL, включая CRLF
и исходный пробел в конце строки: Git autoCRLF не должен менять хеш лицензии
после checkout. Первая staged-проверка выявила этот исходный пробел; последующая
проверка с адресным атрибутом лицензии проходит без изменения её текста.
Дополнительно прочитаны байты всех 66 файлов непосредственно из Git index;
их SHA256 также совпали с доставленным отчётом.

Валидатор не импортирует генератор: повторно открывает сохранённый `.blend`,
проверяет метры, 30 fps, корневые pivot у начала координат, UV/material slots,
доступность текстур/шрифта, конечность координат и отсутствие пустых/вырожденных
граней; затем импортирует 12 моделей и 2 клипа FBX в чистые сцены Blender.

Проверены пустые проходы арок, выборочные просветы двери и свободный вертикальный

Клипы имеют кадры 0–60 при 30 fps (2 с). `door_open`: углы петли

Это фактические числа экспорта, не доказательство игрового бюджета GPU/памяти.

## Визуальная проверка и трактовки

Исполнитель открыл финальные `previews/foundation_modules.png` и
`previews/dremma_scale_comparison.png`. Читаются кладка с фасками, арочные
проёмы, отдельные каменные ступени, ковка с латунью, янтарные фонари, бордовый
баннер и дверная створка. Сравнительный лист показывает четыре подписанных
роста, два поручня, обе дорожки и четыре подписанных размерных контура дверей.
Контуры не выдаются за законченные дверные модели. Фигуры — стилизованные
статичные ростовые образцы; окончательное художественное принятие остаётся
за независимым ревью и пользователем.

Сохранённая настройка сцен — Cycles, GPU, 48 samples; три основных превью
1600×1200, сравнение Дрёммы 2400×1600. Это сведения конфигурации рендеров,
не отдельное измерение используемого GPU или производительности.

Глубина прохода моста 3 м выведена автором; внешняя глубина с декором 3,54 м.
Старые предполагаемые ширины фигур не используются как точные ограничения:
реестр хранит наблюдённые размеры тела отдельно от внешних bounds с хвостом
и посохом. Подпись основного марша исправлена с прежних «9 steps» на 8;
его подъём и вынос соответствуют новой паре дорожек. Неуказанные оси и
противоречия пользовательских листов документированы, общий масштаб моделей
не подгоняется к декоративному bounding box.

Исходные пользовательские bitmap-референсы доступны в разговоре, но отсутствуют
в checkout. Карты созданы процедурно; Noto Sans скопирован из уже используемых
игрой ресурсов с OFL. Происхождение зафиксировано в `Content/credits.json`.

## Остающаяся приёмка

Не выполнены независимое повторное ревью исправлений, native Stride модель/материал/анимация и prefab,
повторный импорт, Save/reopen, игровой runtime, occlusion/traversal, самостоятельный
ZIP, GUI/Game Studio, полный Release редактора или remote CI. Проверка Blender
не подтверждает эти сценарии. Native-приёмка первого этапа зависит от A1.3/A1.4;
карточка остаётся открытой. Следующие 123 модели, механизмы и итоговая библиотека
не входят в готовый исходный срез. Игровые motor/collider/камера не изменены.

## Исправления после первого независимого ревью

Три замечания P2 воспроизведены и исправлены отдельным срезом после родительского
commit `59182a5`; статусы карточки исполнитель не менял.

1. **Внешний report при `--record-catalog`.** В копии исходников
   `build/canal-city/review-regression-before/fixture` старый validator завершался
   с `ValueError`, оставляя внешний JSON со статусом `passed`, но не обновляя
   каталог. Теперь parser проверяет разрешённый путь до загрузки `.blend`:
   повторная проба вернула ненулевой код и ясное сообщение, внешний отчёт не
   создан, каталог побайтово не изменён. Обычная запись внутри нового output
   завершилась успешно и сохранила `source_validation_report: validation-report.json`.
2. **Створка пересекала косяк при вращении.** Добавленная проверка evaluated
   геометрии воспроизводит пересечение старой фурнитуры уже на кадре 0; независимое
   ревью также обнаружило проникновение деревянной створки при открытии.
   Петля вынесена перед выступающим обрамлением на Y=−0,34 м, ствол шарнира
   совмещён с осью вращения. Новая BVH-проверка пересечений поверхностей и
   попадания вершин внутрь кладки проходит на каждом кадре 0–60 для source и
   обоих импортированных FBX-клипов, включая движущуюся фурнитуру.
3. **Уши взрослого 2,8 м задевали арку.** Проверка исходной модели воспроизвела
   препятствие у X=−0,523544, Z=2,679632 м. Начало арки поднято с 1,92 до 2,1 м;
   общая ширина 1,6 м и высота 3 м сохранены, створка строится по тому же профилю.
   Проход всех 2746 evaluated вершин тела/одежды по центру вдоль Y теперь не
   пересекает обрамление. Высота фигуры 2,79999995 м; хвост и посох исключены.
   Это проверка конкретного статичного образца, не гарантия прохода всех поз
   или будущего игрового collider.

Полный output заново создан один раз в `build/canal-city/review-fixed-01`,
проверен с внутренним `--record-catalog`, затем скопирован поверх только
принадлежащих генератору Resources без удаления чужих файлов. После переноса
выполнен отдельный Blender reopen/FBX round trip; отчёты совпадают. Новые
`dremma_scale_comparison.png` и `door_lantern_detail.png` открыты исполнителем:
профиль проёма, створка, размерные подписи и четырёхростовое сравнение читаются.
Vault checker и 25 Python-тестов повторно прошли после исправлений.
