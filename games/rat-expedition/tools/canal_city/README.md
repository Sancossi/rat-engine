# Канальный город — исходный набор Blender

Созданы **12 исходных моделей**: набережная, арочный мост, каменная лестница,
ограда1 м, янтарный фонарь, готическая дверь, четыре ростовые фигуры,
ограда1,5 м и совмещённая каменно-деревянная лестница. Реестр содержит **135**
уникальных вариантов по трём листам и уточнениям Дрёммы; остальные123 позиции
пока не изготовлены. Проверка Blender/FBX не означает приёмку Stride.

Готовый набор: `../../Rat.Expedition.Authoring/Resources/CanalCity/`.
Откройте `canal_city_foundation.blend`. Сцены:

- `DIORAMA | Lantern crossing` — собранный переход через канал;
- `PREVIEW | Six foundation modules` — все шесть модулей;
- `DETAIL | Door and amber lantern` — крупный план;
- `SCALE | Dremma generations` — четыре роста, четыре размерных контура проёмов,
  два поручня, совмещённая лестница и готовая средняя дверь;
- `SOURCE | Editable modules` — редактируемые коллекции у общего начала координат.

В SOURCE включайте нужную коллекцию, остальные временно скрывайте. Каждый камень,
элемент ковки и дверная деталь остаётся отдельным объектом с редактируемыми фасками.
Сценические экземпляры используют те же коллекции. Не редактируйте генератор поверх
ручных изменений `.blend`: он намеренно отказывается писать в существующий output.

## Воспроизведение

Из корня репозитория; выберите **новую** папку для каждого запуска:

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' --factory-startup --background --python-exit-code 1 --python games/rat-expedition/tools/canal_city/build.py -- --output build/canal-city/my-version
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' --factory-startup --background --python-exit-code 1 --python games/rat-expedition/tools/canal_city/validate.py -- --input build/canal-city/my-version --report build/canal-city/my-version/validation-report.json --record-catalog
```

`--factory-startup` исключает пользовательские дополнения; скрипт не меняет их
настройки. Blender 5.2 включает используемый NumPy. `--skip-render` пропускает
только PNG-превью; материалы и FBX всё равно создаются. Генерация детерминирована
по геометрии и текстурам, но служебные Blender/FBX идентификаторы не обязаны быть
побайтово одинаковыми. Перед переносом нового output в Resources сравните изменения
и сохраните ручные исходники. Предыдущий проверенный генераторный набор сохранён
в checkpoint `d8b513e`; он не подтверждает новый масштаб. Текущий output создан
в свежей build-папке, проверен и намеренно перенесён поверх только принадлежащих
генератору файлов Resources. Доставленные ассеты имеют отдельный отчёт проверки.
При `--record-catalog` путь `--report` должен находиться внутри `--input`, чтобы
ссылка в каталоге была переносимой. Внешний путь отвергается до открытия Blender
и записи файлов; без `--record-catalog` внешний отчёт разрешён.

## Размеры и экспорт

Blender: метры, Z вверх, фасад смотрит в −Y. FBX: Y вверх, −Z вперёд, unit scale 1;
импортёр обязан учитывать FBX metadata. Корневой pivot находится у основания
модуля; у лестницы Y=0 — передний край. Сетка размещения 1 м с детализацией 0,25 м
не округляет явно подписанные размеры. Отчёт хранит фактические габариты с декором.

| Модуль | Основные размеры и трактовка |
|---|---|
| Набережная | W8 × D4 × H4,5 м; условно настил H3,75 + фонари 0,75. Кольца/анкеры выступают вперёд на 0,23 м |
| Мост | W8 м, H5 м вместе с фонарями; настил H3,1 м, предполагаемая ширина прохода D3 м |
| Каменная лестница | W2,4, D4,48, подъём2,4 м; 8 подъёмов по0,30, проступь0,56 м. Перила выше подъёма |
| Совмещённая лестница | Те же W2,4 / D4,48 / H2,4; 8 каменных и16 деревянных ступеней. Малый шаг0,15 /0,28 м, дорожка0,8 м с полезной шириной0,6 |
| Ограждения | Длина стыковки2 м; верхняя поверхность поручня ровно1,0 или1,5 м над настилом |
| Дверь | Световой проём W1,6 × H3,0, глубина0,4 м; каменная рама снаружи |
| Фонарь | Отдельная головка H0,75 м, около0,36 ×0,36 м; размеры выведены из окружения |
| Ростовые фигуры | Ребёнок1,2; небольшой взрослый1,8; обычный житель2,8; взрослый дрёмец4,0 м. Рост от подошвы до головы/ушей, без посоха/хвоста |

Последний именованный масштаб Дрёммы имеет приоритет; прежние размеры сохранены
в `previous_dimension_revision`. Для совмещённой лестницы сознательно выбраны
каменные0,30 м из диапазона0,30–0,50: две малые ступени0,15 точно дают одну большую.
Внутри общей ширины сделана ступенчатая выемка под малую дорожку: деревянные
ступени лежат над своим основанием, не скрываются в крупных каменных подступенках.
Обе дорожки имеют один верх и свободный выход. Фигуры — статичные художественные
образцы масштаба, не игровые3D-персонажи.

Противоречия листов сохранены в `catalog.json`. Новый высокий проём —2,2×4,2,
парадный —3,5×6, несмотря на противоречащие им стрелки. Четыре прямоугольных
контура на сравнении подписаны как размерные направляющие, а не готовые дверные
модели. Из дверей изготовлена только средняя. Неизвестные оси отмечены `null`,
а предполагаемые размеры — отдельно. Двери описывают проём; лестницы — подъём;
площадки — высоту настила с оградой без подвесных опор. Весь каталог не следует
автоматически приводить к размеру декорированного bounding box. Параметры домов,
общественных фасадов, этажей, потолков и поколений города включены в каталог;
полноценные интерьеры не создаются. Будущий ориентир игровых визуалов0,8/2,8;
текущие motor/collider/камера не изменялись.

`models/` содержит12 FBX. Экспорт применяет фаски, триангулирует и удаляет
численно вырожденные грани, объединяет меши по назначению: настил, опоры, арка,
ковка, ткань, рама и створка. Такая группировка сохраняет будущие traversal/occlusion
границы. Collision geometry и native prefab этой исходной поставкой не создаются.

`animations/door_open.fbx` и `door_close.fbx`: 30 fps, кадры0–60, длительность2 с,
поворот петли вокруг локальной Z между0° и−100°. Анимация жёсткого узла, без
скининга; геометрия створки наследует петлю. При проверке в Blender задаётся
`anim_offset=0`, так как стандартный импортёр добавляет один кадр. В SOURCE
петля `door_hinge` содержит action открытия; оба клипа сохранены как Actions.
Петля вынесена перед каменным обрамлением, чтобы створка открывалась наружу без
пересечения кладки. Плечи арки подняты до 2,1 м при прежнем проёме 1,6 × 3 м:
обычный житель 2,8 м с ушами и одеждой проходит по центру открытого проёма.

Общие карты `basecolor`, `normal`, `roughness`, `metallic` — PNG256×256 с повторением
UV; у amber дополнительно emission. `materials.json` задаёт соответствия и
интенсивность свечения4. Всего45 карт, включая материалы меха и ушей новых фигур.
Все карты процедурные, без сторонних bitmap. Для русских размерных подписей
добавлена копия уже используемого в игре Noto Sans с `fonts/OFL.txt`; зависимость
переносится вместе с исходником. Материалы
Stride нужно создать отдельно по этому описанию; FBX не переносит весь shader graph.
Сценическая вода использует Blender shader и не является игровым экспортом.

## Независимая проверка

`validate.py` не импортирует генератор. Он повторно открывает доставленный `.blend`,
проверяет UV, материалы, текстуры, конечность координат, непустую геометрию,
восемь крупных и16 малых высот ступеней, совпадение верхов, свободный объём над
малыми проступями, четыре роста без аксессуаров, верхние поверхности поручней,
световой проём и пустые арочные проходы; затем импортирует все14 FBX
в чистые сцены и сравнивает bounds/петлю/клипы. Отчёт содержит SHA256 артефактов.
Все 61 кадр source-анимации и обоих FBX-клипов проверяются на пересечение
evaluated геометрии створки вместе с фурнитурой и каменного обрамления. Отдельно
проверяется проход вершин тела/одежды обычного жителя через проём вдоль Y;
хвост и посох исключены из этой размерной проверки.
Рендеры необходимо дополнительно осматривать; автоматический `passed` не является
художественным одобрением или свидетельством запуска игры.
